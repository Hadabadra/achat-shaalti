# רשימת בדיקה ידנית ב-Windows

לפני כל שחרור: לעבור על הרשימה במחשב Windows אמיתי (רצוי גם עם הנעילה הקפדנית מותקנת). לסמן ✅/❌ ולפתוח issue על כל כשל.

## התקנה ועדכון (#21)
- [ ] התקנה נקייה: הגשר עולה במגש, התוספים מותקנים באוצריא.
- [ ] עדכון כשהשירות מותקן והנעילה כבויה → UAC אחד, השירות עולה בגרסה החדשה.

- [ ] ביטול UAC לא מפיל את ההתקנה.

## צילום מסך וחלונות הגשר (#60)
- [ ] Ctrl+Shift+F11 (מלא) ו-Ctrl+Shift+F12 (אזור) — גם בנעילה; Esc מבטל בחירת אזור.
- [ ] בחירת אזור במסכים מרובים; הקובץ נשמר בתיקייה מותרת כשהסייר מוגבל.
- [ ] פריטי המגש "צילום מסך"/"צילום אזור".
- [ ] סרגל הנעילה: "אודות", "דיווחים", "מה חדש", "צילום מסך" נפתחים מעל הנעילה.
- [ ] טאב "תוכנות לימוד": הוספה/הסרה (סיסמה), הצעות זיהוי, "העבר לחזית", מתג זיהוי אוטומטי.
- [ ] "מצב נעילה": כרטיס התוכנות מציג סיכום וכפתור מעבר.
